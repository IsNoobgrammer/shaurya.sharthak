# Shaurya Sharthak — Portfolio

Research-oriented personal portfolio website built with React, Vite, and Three.js.

## Tech Stack
- **Frontend:** React + Vite
- **Styling:** Vanilla CSS (Glassmorphic Midnight lab theme)
- **3D/Animations:** Three.js, Framer Motion
- **Icons:** Lucide React

## Features
- Custom Three.js particle background with interactive Easter Egg (Gita mode).
- Folder-based blog system directly fetching from a public GitHub repository.
- Responsive project catalog with category filtering.
- Dynamic skill grids and verbose interactive About section.
- **Personality-Driven Theming System:** 12 glassmorphic/brutalist themes with a "Let me be lucky" random generator.
